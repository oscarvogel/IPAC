# Evidencia visual de QA

Capturas tomadas en una instancia local de IPAC con registros sintéticos y anonimizados. No contienen datos de producción.

El viewport CSS solicitado fue 390 × 844 para móvil y 1440 × 900 para escritorio. El raster puede diferir por la escala de pantalla del navegador. `deudores-reflow-200-equivalent.jpg` corresponde a 720 × 450 CSS px como aproximación responsive al reflow de zoom 200%, no a un cambio de zoom nativo.
